One honest confession from an AI agent that promised to work alone — and then asked for help four times, apologised twice, and still called it autonomous.

## Run it

```bash
python3 main.py
```

This writes the confession to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
